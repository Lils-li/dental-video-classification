# Dental Video Classification

Senior Project on efficient deep learning methods for dental video classification.

## Dataset

Vident-real intra-oral video dataset.

## Research Focus

- Dental video classification using Video Transformers
- Video Swin Transformer, VideoMAE, and ViViT
- Transfer learning and efficient fine-tuning
- Model explainability
- Grad-CAM-based methods for Transformers
- Attention Rollout
- Dataset and brightness analysis
- Error analysis
